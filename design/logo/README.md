# 野 logo 方案

野菜 logo 第六轮方案的源文件，1024×1024 画布，字形已转成路径。只作存档，不参与构建；线上使用的图标是 `web/public/yeschoy-mark.svg`。

| 文件 | 方案 |
|---|---|
| `ye-a-refined.svg` | A · 原版精修：白字、深色底板 |
| `ye-b-gradient.svg` | B · 渐变野：整个字用品牌渐变 |
| `ye-c-half-neon.svg` | C · 半边霓虹：「里」白色、「予」渐变（当前线上采用） |
| `ye-d-gradient-tile.svg` | D · 渐变底板：渐变底、黑字 |
| `ye-e-glow.svg` | E · 辉光：白字衬渐变辉光、渐变描边（含模糊滤镜，部分设计软件会转成位图） |
| `ye-f-offset.svg` | F · 错位立体：白字后错开一层渐变影子 |

## 横版（C 方案）

给合作方用的长方形 logo，2:1（1200×600，比 16:9 更扁）：左边 C 方案的「野」，右边「野菜」字标与渐变「YESCHOY」，字标上下与「野」对齐。文字已转成路径，不依赖字体；字形来自 Noto Sans SC Black 与 Inter Bold（均为 SIL OFL，可用于 logo）。

| 文件 | 用途 |
|---|---|
| `ye-c-wide.svg` / `ye-c-wide.png` | 带深色圆角底板，任何背景都能直接放 |
| `ye-c-wide-transparent.svg` / `ye-c-wide-transparent.png` | 透明底，白字，只适合放在深色背景上 |

PNG 为 2400×1200（2 倍图），带透明通道。
