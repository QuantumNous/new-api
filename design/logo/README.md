# 野 logo 方案

野菜 logo 第六轮方案的源文件，1024×1024 画布，字形已转成路径。只作存档，不参与构建；线上使用的图标是 `web/public/yeschoy-mark.svg`。

| 文件 | 方案 |
|---|---|
| `ye-a-refined.svg` | A · 原版精修：白字、深色底板 |
| `ye-b-gradient.svg` | B · 渐变野：整个字用品牌渐变 |
| `ye-c-half-neon.svg` | C · 半边霓虹：「里」白色、「予」渐变（当前线上采用） |
| `ye-d-gradient-tile.svg` | D · 渐变底板：渐变底、黑字 |
| `ye-e-glow.svg` | E · 辉光：白字衬渐变辉光、渐变描边（含模糊滤镜，部分设计软件会转成位图） |
| `ye-f-offset.svg` | F · 错位立体：白字后错开一层渐变影子 |

## 横版（C 方案）

给合作方用的长方形 logo，参考快跑云横版 logo 的做法：左边 C 方案的「野」，右边「野菜」在上、「YesChoy」在下，两行左对齐，「YesChoy」字距拉到与「野菜」同宽；文字块约为图标高度的 78%，与图标垂直居中。透明底，画布 2:1（1200×600，比 16:9 更扁），logo 居中留白。文字已转成路径（Noto Sans SC Bold、Inter Bold，均为 SIL OFL），不依赖字体。

| 文件 | 用途 |
|---|---|
| `ye-c-wide.svg` / `ye-c-wide.png` | 浅色背景用：「里」和文字为近黑色，「予」用加深的绿色渐变 |
| `ye-c-wide-dark.svg` / `ye-c-wide-dark.png` | 深色背景用：「里」和文字为白色，原渐变 |

PNG 为 2400×1200（2 倍图），带透明通道。
