# Qupper's Forge 赛事站用 logo

给 https://qupper.fastrun.com.cn/ 展示野菜用的素材，按该站实际的两个 logo 位置设计。该站为深色背景。

| 文件 | 用在哪 | 说明 |
|---|---|---|
| `qf-wide-dark.svg` / `.png` | 页脚「主办/联合主办单位」区等深色背景横版位（约 160×42） | C 方案「野」+ 上下排「野菜 / YesChoy」，白字、原渐变，贴边裁切，约 2.36:1 |
| `qf-wide.svg` / `.png` | 白底横版位 | 同上，近黑字 + 加深绿色渐变 |
| `qf-wide-black.svg` / `.png` | 需要自带底色的长方形 logo 位 | 黑底（`#0A0C0F`，不透明、直角），2:1（比 16:9 更扁），「野」+ 上下排「野菜 / YesChoy」居中，白字、原渐变 |
| `qf-square.svg` / `.png` | 「合作生态」滚动卡片左侧的浅色小方块（约 62px） | 方形「野」，近黑「里」+ 加深渐变 |
| `qf-square-dark.svg` / `.png` | 深色背景的方形位 | 白色「里」+ 原渐变 |

- 横版 PNG 2400×1018，黑底横版 PNG 2400×1200，方形 PNG 1024×1024；除黑底版外均为透明底。
- SVG 文字已转成路径（Noto Sans SC Bold、Inter Bold，均为 SIL OFL），不依赖字体。
- `preview-partners.png`、`preview-footer.png`：把素材替换进该站页面后的本地截图，仅供参考。
- 合作卡片的文字建议填「野菜」/「模型供应商」。
