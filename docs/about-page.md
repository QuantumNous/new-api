# 随星知 API

**一个入口，接入你需要的大部分 AI 能力。**

随星知 API 是面向开发者与企业的统一 AI 能力网关：把对话、向量、图像、视频、语音等模型收敛到同一套 API、同一把密钥、同一份账单。

## 为什么用它

- **一次接入，长期可用**：兼容 OpenAI / Anthropic / Gemini 三种主流协议，已有代码只改 `base_url` 和密钥即可迁移，SDK 不用动。
- **模型覆盖广**：内置 59 种上游渠道类型，覆盖 OpenAI、Claude、Gemini、DeepSeek、通义千问、豆包、Kimi、智谱、混元、MiniMax 等国内外主流模型。
- **多模态打通**：文本、向量、图像之外，视频与音频任务同样走统一入口。
- **账单可解释**：每一次调用都有明细，按 token、按次、按分档表达式都能计价。

## 支持的能力

| 能力 | 说明 |
| --- | --- |
| 对话与推理 | OpenAI Chat Completions / Responses、Anthropic Messages、Gemini generateContent 全部兼容 |
| 向量嵌入 | `/v1/embeddings`，兼容主流 embedding 模型 |
| 图像生成 | `/v1/images/generations`，支持多尺寸与不同风格模型 |
| 视频生成 | 覆盖 Sora 2、Veo 3、可灵 Kling、海螺 Hailuo、Vidu、即梦、豆包 Seedance、通义万相、Grok Imagine 等，异步任务轮询 |
| 语音与音乐 | 语音合成、Suno 音乐生成 |
| 重排序 | Jina Rerank 等重排接口 |

视频与音频类任务由插件驱动，新增上游模型通常不需要升级平台，配置即可上线。

## 上手只要三步

1. 注册账号，在「钱包」充值或使用兑换码获得额度；
2. 在「密钥」页创建 API Key，选择可用分组；
3. 把 SDK 的 `base_url` 指向 `https://token.35sz.top/v1`，填入密钥即可。

## 计费与账务

- **三种计费模式并存**：按 token、按次、按分档表达式（例如视频按秒数 × 分辨率）独立配置，同一平台内模型之间互不影响。
- **缓存单独计价**：命中提示词缓存的读写单独计费，长上下文场景更省。
- **分组倍率**：不同用户组可配置不同倍率，适合团队协作与渠道分销。
- **实时对账**：用量日志逐条可查，账单不靠猜。

## 稳定性与运维

- **多渠道自动路由**：同一模型可挂多个上游，按优先级与权重分发。
- **失败重试与自动熔断**：异常渠道自动禁用，不拖累整体可用性。
- **价格同步**：上游调价后可同步，并按站点汇率换算成本地价格。
- **全链路留痕**：谁、何时、调了什么模型、消耗多少，请求日志与审计记录都能追溯。

## 团队与运营

- **密钥与访问令牌**：支持细粒度作用域，按最小权限发放。
- **钱包、订阅、兑换码**：适配预付费与套餐制两种结算习惯。
- **邀请返佣**：推荐新用户可获得返佣，适合渠道合作。
- **七种界面语言**，明暗主题自适应。
