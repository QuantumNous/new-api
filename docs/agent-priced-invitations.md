# 按链接定价的代理邀请

状态：2026-09-07 本地实现并验证，尚未部署。当前线上仍是上一版统一代理价。

## 用户流程

代理设置 0.02～0.06 元/张，点击“生成链接”。每次生成一个独立随机链接，价格在生成时固定，多个价格的链接可以同时使用。左侧分别展示价格、链接、有效时间和复制按钮；客户列表增加每名客户的生图价格。

链接从服务器创建时起有效 2 小时。有效期内可以邀请多个新客户；过期后不能继续注册，需要生成新链接。每个代理最多同时保留 20 个有效链接。

新客户通过链接使用用户名和密码注册，注册页先展示对应单价。首次注册时绑定代理及价格；已有账号不能通过另一条链接覆盖价格或改变归属。链接过期不影响已注册账号的价格，生成新链接也不改变已注册客户或其他链接的价格。

新链接采用 `/sign-up?invite=<随机令牌>`，不会把金额作为可信 URL 参数。原有普通 `aff` 邀请码继续记录邀请关系，但新注册客户不能仅凭永久 `aff` 地址取得特殊价格。升级时已开通代理的历史直接客户按原有价格生成固定记录，后续改默认价不会重定价。

此版专属价格注册入口只显示用户名/密码注册方式，避免第三方登录丢失价格绑定。普通注册页的 OAuth/微信入口保持原状。链接有效性以服务器最终注册时的校验为准；失效时拒绝注册，不自动退回平台价格创建账号。

## 实现

- `agent_invitations`：随机令牌、代理、固定分值、创建时间、失效时间。只有发行代理能列出自己的有效链接；公开预览只返回价格和有效期。
- `agent_customer_prices`：客户 ID 唯一、代理 ID、固定分值、来源令牌、创建时间。价格长期保存，报价和扣费读取客户绑定记录。
- `agent_profiles.customer_prices_locked`：标记历史价格迁移完成，启动重跑不会覆盖历史价格。
- 登录代理 GET/POST `/api/agent/invitations` 列表/生成；公开 GET `/api/agent-invitations/:token` 校验并预览。
- 注册 POST `/api/user/register` 支持 `agent_invite`。优先采用链接所属代理，忽略客户端伪造的金额、角色以及冲突的旧 `aff_code`。
- 用户插入与价格绑定位于同一事务；有效性在密码处理及等待锁之后再次检查。存储绑定失败时回滚账号，避免用户被创建却未取得约定价格。
- 原有批次报价快照、API Images 预扣、结算、退款继续使用服务端报价；停用代理后沿用原平台价回退规则，已提交批次保留提交时的价格。

## 验证

controller 全包、model 全包、relay/helper 全包通过；后续针对历史绑定、到期和事务回滚的增补测试通过。确认 6 分/2 分注册客户并存，旧客户保价，伪造参数无效，过期注册不留下账号，链接到期不影响已绑定价格，绑定写入失败回滚账号，有效链接数量限制不计算已过期链接。已有批次、API 实际结算及异步退款用例按固定客户价更新并通过。

前端相关 12 个测试、类型检查、相关文件 lint、生产构建及 Go 编译通过。Chrome 在本地模拟数据上检查桌面及 390px 手机布局、两种价格链接并列、客户价格列、有效注册预览及失效链接禁止注册。未调用收费模型，未改变生产账号、价格或部署。
