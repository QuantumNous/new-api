MiniMax H3 视频生成 API

通过统一的 /v1/videos 接口调用 MiniMax-H3，支持文生视频、首尾帧图生视频和图片 / 视频 / 音频参考生成。接口采用「创建任务 → 轮询状态 → 下载视频」的异步流程，对外仅暴露公共任务 ID。

1. 概览

项值
模型MiniMax-H3
调用模式异步：创建任务 → 轮询 → 下载视频
能力文生视频、单帧 / 首尾帧图生视频、多图片参考、参考视频、参考音频
输出分辨率768P、2K
输出时长4–15 秒
结果交付完成后从 metadata.url 获取临时 MP4 地址
区域MiniMax 国际站；价格按美元计算

下文中的 {BASE} 指 NewAPI 服务地址，例如 https://your-api-host。

2. 认证

客户端使用 NewAPI 访问令牌鉴权。MiniMax 上游 Key 保存在渠道配置中，不会返回给客户端。

Authorization: Bearer sk-xxxxxxxxxxxxxxxx

3. 接口一览

方法 & 路径说明鉴权
POST/v1/videos创建视频生成任务Bearer
GET/v1/videos/{task_id}查询任务状态、用量和结果Bearer

本文推荐使用 /v1/videos。创建响应中的 id / task_id 是 NewAPI 生成的公共任务 ID；MiniMax 上游任务 ID 不会对外暴露。

4. 创建视频任务

POST{BASE}/v1/videos

请求参数（JSON Body）

字段类型必填说明
modelstring必填固定为 MiniMax-H3，或使用已映射到该模型的客户端别名
contentarray必填多模态输入数组；必须至少包含一条非空文本
resolutionstring必填768P 或 2K，区分大小写
durationint必填输出时长，范围 4–15 秒
ratiostring条件必填21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / adaptive。纯文本请求必须显式填写非 adaptive 比例；带媒体时省略则自动使用 adaptive
aigc_watermarkbool可选是否添加 AIGC 水印；显式传入 false 会原样发送
callback_urlstring不支持当前版本会返回 unsupported_callback_url，请使用轮询查询状态

content 元素

type附带字段role说明
texttext不可填写非空提示词；全部文本累计最多 7000 个 Unicode 字符
image_urlimage_url.url省略 / first_frame / last_frame / reference_image省略 role 等同于 first_frame；首帧和尾帧各最多 1 张；参考图片最多 9 张
video_urlvideo_url.urlreference_video参考视频，最多 3 段
audio_urlaudio_url.urlreference_audio参考音频，最多 3 段；必须同时提供参考图片或参考视频

输入组合限制：首帧 / 尾帧模式不能与 reference_image、reference_video 或 reference_audio 混用。每个 content 元素必须且只能携带与其 type 匹配的一种载荷。

请求示例（文生视频）

curl --fail-with-body "{BASE}/v1/videos" \
  -H "Authorization: Bearer sk-xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MiniMax-H3",
    "content": [
      { "type": "text", "text": "纸船穿过雨后的水洼，电影感微距镜头" }
    ],
    "resolution": "768P",
    "duration": 6,
    "ratio": "16:9",
    "aigc_watermark": false
  }'

请求示例（首尾帧图生视频）

curl --fail-with-body "{BASE}/v1/videos" \
  -H "Authorization: Bearer sk-xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MiniMax-H3",
    "content": [
      { "type": "text", "text": "镜头缓慢拉远，晨雾穿过山谷" },
      {
        "type": "image_url",
        "image_url": { "url": "https://example.com/first.jpg" },
        "role": "first_frame"
      },
      {
        "type": "image_url",
        "image_url": { "url": "https://example.com/last.jpg" },
        "role": "last_frame"
      }
    ],
    "resolution": "2K",
    "duration": 8,
    "ratio": "adaptive"
  }'

请求示例（图片 / 视频 / 音频参考）

curl --fail-with-body "{BASE}/v1/videos" \
  -H "Authorization: Bearer sk-xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MiniMax-H3",
    "content": [
      { "type": "text", "text": "保持人物与运动风格，让角色穿过雪中的街道" },
      {
        "type": "image_url",
        "image_url": { "url": "https://example.com/character.jpg" },
        "role": "reference_image"
      },
      {
        "type": "video_url",
        "video_url": { "url": "https://example.com/motion.mp4" },
        "role": "reference_video"
      },
      {
        "type": "audio_url",
        "audio_url": { "url": "https://example.com/ambience.mp3" },
        "role": "reference_audio"
      }
    ],
    "resolution": "768P",
    "duration": 10,
    "ratio": "adaptive"
  }'

创建响应

保存 id 或 task_id，后续查询均使用这个 task_ 开头的公共任务 ID。

5. 查询任务状态

GET{BASE}/v1/videos/{task_id}

curl --fail-with-body "{BASE}/v1/videos/task_3f9a...e2" \
  -H "Authorization: Bearer sk-xxxx"

排队 / 进行中

{
  "id": "task_3f9a...e2",
  "task_id": "task_3f9a...e2",
  "object": "video",
  "model": "MiniMax-H3",
  "status": "in_progress",
  "progress": 50,
  "created_at": 1785859200
}

完成

{
  "id": "task_3f9a...e2",
  "task_id": "task_3f9a...e2",
  "object": "video",
  "model": "MiniMax-H3",
  "status": "completed",
  "progress": 100,
  "usage": {
    "completion_tokens": 4,
    "total_tokens": 10
  },
  "metadata": {
    "url": "https://temporary-download.example.com/output.mp4"
  },
  "created_at": 1785859200,
  "completed_at": 1785859318
}

完成后从 metadata.url 下载视频。对 H3 而言，共享视频 DTO 中的 usage.completion_tokens 表示输出秒数，usage.total_tokens 表示总计费秒数（参考视频输入秒数 + 输出秒数），不是语言模型 token 数。

注意时效：metadata.url 是 MiniMax 返回的临时 CDN 地址。任务结果冻结后，重复查询不会刷新该地址；请在地址失效前尽快下载并保存到自己的存储。

失败

{
  "id": "task_3f9a...e2",
  "task_id": "task_3f9a...e2",
  "object": "video",
  "model": "MiniMax-H3",
  "status": "failed",
  "progress": 100,
  "error": {
    "message": "...",
    "code": "..."
  }
}

明确失败或取消的任务会走退款流程，退回已预扣额度。

6. 获取视频

任务状态为 completed 后，直接 GET metadata.url：

URL=$(curl -sS "{BASE}/v1/videos/task_3f9a...e2" \
        -H "Authorization: Bearer sk-xxxx" | jq -r '.metadata.url')

curl --fail --location "$URL" --output output.mp4

仅在任务完成后才会返回 metadata.url。请勿将临时地址当作长期存储地址。

7. 状态值

status含义
queued任务已创建，等待执行
in_progress正在生成，progress 为 0–100
completed生成完成，结果位于 metadata.url
failed生成失败，详情位于 error

8. 用量与计费

国际站参考价格：

计费项价格
768P 输出$0.08 / 秒
2K 输出$0.13 / 秒
参考视频输入按输入视频时长和所选输出分辨率计费
输入图片 1–5 张免费
第 6 张及以后$0.04 / 张
参考音频免费
基础金额 = total_seconds × 分辨率秒价
         + max(input_image_count - 5, 0) × $0.04

示例：

请求参考金额
768P、4 秒输出4 × $0.08 = $0.32
2K、4 秒输出4 × $0.13 = $0.52
768P、6 秒参考视频 + 4 秒输出10 × $0.08 = $0.80
768P、4 秒输出 + 6 张图片4 × $0.08 + $0.04 = $0.36

含参考视频的请求在提交时会按最多 15 秒输入时长预扣；任务成功后根据上游返回的实际 total_seconds 和图片数量结算，多预扣部分退回。最终用户扣费还会受到站点分组倍率、订阅规则等配置影响。

9. 错误与限制

请求 / 提交阶段错误体：

{
  "code": "invalid_ratio",
  "message": "text-only generation requires a non-adaptive ratio",
  "data": null
}
错误码 / 场景说明
unsupported_model渠道映射后的上游模型不是 MiniMax-H3
invalid_model请求未提供模型
invalid_durationduration 不在 4–15 秒范围内
invalid_resolutionresolution 不是 768P 或 2K
invalid_ratio比例值不支持，或纯文本请求省略比例 / 使用 adaptive
invalid_content文本为空、role 错误、素材数量超限或输入组合冲突
unsupported_callback_url当前版本不支持回调，请使用轮询
额度不足预扣失败，任务不会提交到上游

当前不支持任务列表、删除、取消、再生成、remix 和 MiniMax-H3-Context-IR。媒体格式、尺寸和远程 URL 可访问性最终仍以上游校验为准。

10. 完整示例（创建 → 轮询 → 下载）

#!/usr/bin/env bash
set -euo pipefail

BASE="https://your-api-host"
TOKEN="sk-xxxxxxxxxxxxxxxx"

# 1) 创建任务
RESP=$(curl --fail-with-body -sS "$BASE/v1/videos" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MiniMax-H3",
    "content": [
      { "type": "text", "text": "宇航员在月球漫步，电影感，镜头缓慢推近" }
    ],
    "resolution": "768P",
    "duration": 4,
    "ratio": "16:9"
  }')

TASK_ID=$(echo "$RESP" | jq -r '.id')
test -n "$TASK_ID" && test "$TASK_ID" != "null"
echo "task: $TASK_ID"

# 2) 轮询直到完成或失败
while true; do
  Q=$(curl --fail-with-body -sS "$BASE/v1/videos/$TASK_ID" \
        -H "Authorization: Bearer $TOKEN")
  STATUS=$(echo "$Q" | jq -r '.status')
  echo "status: $STATUS"

  if [ "$STATUS" = "completed" ]; then
    break
  fi
  if [ "$STATUS" = "failed" ]; then
    echo "failed: $(echo "$Q" | jq -r '.error.message')" >&2
    exit 1
  fi
  sleep 5
done

# 3) 下载视频
URL=$(echo "$Q" | jq -r '.metadata.url')
OUTPUT_SECONDS=$(echo "$Q" | jq -r '.usage.completion_tokens // empty')
TOTAL_SECONDS=$(echo "$Q" | jq -r '.usage.total_tokens // empty')
echo "output seconds: $OUTPUT_SECONDS; total billable seconds: $TOTAL_SECONDS"

curl --fail --location "$URL" --output output.mp4
echo "saved -> output.mp4"
