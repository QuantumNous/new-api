# 控制台功能可见性

更新时间：2026-08-14

## 套餐入口

默认 Vue 控制台暂时隐藏以下导航入口：

- `套餐`：`/console/subscription`
- `套餐管理`：`/console/plan-management`

这是导航可见性调整，不是功能下线。两个路由、现有登录与管理员权限守卫、订阅状态、后端接口和数据库模型均保留；需要恢复入口时，移除对应导航项的 `hidden` 标记即可。

React 兼容控制台不在本次调整范围内。

## 订单管理文案

订单管理页面不再向用户显示 `Epay` 品牌名，改用通用的充值、在线支付和支付通道表述。API 路径、`epay` 机器字段、统计字段、支付处理分支及导出协议保持不变。
