# 野菜 API UI 交接给 Grok

请继续设计和实现野菜 API 的 UI。不要只在现有 New API 页面上换皮，可以自由调整页面结构、组件和动效。

## 参考网址

- Inspira UI（组件、背景与动效）：https://inspira-ui.com/docs/cn
- Motion Sites（整体动效与全屏布局）：https://motionsites.ai/
- Motion Sites 参考案例（重点）：https://motionsites.ai/?prompt=bl

重点参考 Motion Sites 的全屏镜头、中央人物或吉祥物、鼠标跟随或逐帧交互、超大背景文字、左右错位文案和滚动分镜。保留野菜 API 的多巴胺色彩与现有字体，其余可以自由发挥。

本分支已经包含当前最新的 UI 尝试，可在查看现有页面后自行保留、修改或替换。
