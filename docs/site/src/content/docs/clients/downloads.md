通过下方的 **官方下载页** 获取客户端，安装完成后再按对应教程接入 DeepPattern API。

## CC Switch

[前往官方下载页](https://github.com/farion1231/cc-switch/releases/latest)

macOS 打开 DMG 安装；Windows 运行 MSI。Windows 需已安装 WebView2，Linux 需满足系统运行库依赖。

## ChatGPT(Codex) 桌面端

[前往官方下载页](https://chatgpt.com/download/)

macOS 解压 ZIP 后将 ChatGPT.app 放入「应用程序」。Windows 打开 MSIX 安装。

## Claude Code CLI

[前往官方下载页](https://code.claude.com/docs/en/setup#install-claude-code)

按 [Claude Code 官方安装指南](https://code.claude.com/docs/en/setup#install-claude-code) 安装；运行时需正常连接 DeepPattern API。
