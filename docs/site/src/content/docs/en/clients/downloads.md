Get each client from its **official download page** below, then follow the matching guide to connect it to DeepPattern API.

## CC Switch

[Go to the official download page](https://github.com/farion1231/cc-switch/releases/latest)

On macOS, open the DMG to install. On Windows, run the MSI. Windows requires WebView2; Linux requires the system runtime libraries.

## ChatGPT (Codex) desktop

[Go to the official download page](https://chatgpt.com/download/)

On macOS, unzip the ZIP and move ChatGPT.app to Applications. On Windows, open the MSIX to install.

## Claude Code CLI

[Go to the official download page](https://code.claude.com/docs/en/setup#install-claude-code)

Install it with the [official Claude Code setup guide](https://code.claude.com/docs/en/setup#install-claude-code). It needs a working connection to DeepPattern API at runtime.
