## 计费规则

模型可按 Token、次数、图片或视频计费。价格由模型和服务分组决定，以[模型广场](https://{{API_HOST}}/pricing)及当前计费配置为准。

API Key 可单独设置额度上限。账户余额不设有效期。

## 核对请求费用

1. 打开[使用日志](https://{{API_HOST}}/usage-logs/common)。
2. 按请求时间、密钥和模型查找记录。
3. 核对输入、输出及缓存 Token，或图片、视频等计费数量。
4. 按该模型所在分组的计费规则核对费用，不要直接套用厂商官方价格。

OpenAI Chat Completions 的用量位于响应的 `usage`。流式请求需设置 `stream_options.include_usage`，详见[流式输出](/guides/streaming/)。

## 常见问题

- **费用与预期不同**：检查服务分组、计费方式、输入输出单价及缓存用量。
- **请求失败是否计费**：未产生上游调用的失败请求不计费；已产生输出后中断的请求按实际用量计费。
- **提示额度不足**：检查账户余额和密钥剩余额度；有兑换码时可按[兑换码充值](/start/redeem/)教程增加账户余额，密钥的额度上限需单独调整。
