---
title: 兑换码充值
description: 在钱包中输入兑换码，为当前账户增加可用额度，并核对到账结果。
---

拿到兑换码后，在[钱包](https://{{API_HOST}}/wallet)中兑换，即可把兑换码对应的额度充入**当前登录账户**，用于后续 API 调用。

:::caution[先确认账号，保管好兑换码]
兑换码是充值凭证，每个兑换码只能成功使用一次。兑换前先确认登录的是需要充值的账号，不要把未使用的兑换码公开到群聊、文档或截图。

兑换码**不是 API Key**，不要把它填进客户端的 API Key 输入框。本页配图用说明文字替代真实兑换码，请填写你自己收到的完整兑换码。
:::

## 第 1 步：打开钱包，找到兑换入口

1. 登录 [DeepPattern API 控制台](https://{{API_HOST}}/dashboard)，点击左侧 **个人 → 钱包**，也可以直接打开[钱包页面](https://{{API_HOST}}/wallet)。
2. 找到 **添加资金** 卡片，向下滚动到 **有兑换码吗？** 区域。

## 第 2 步：粘贴兑换码，点击兑换额度

按下图中的 **3–4** 操作：

1. 在 **输入您的兑换码** 输入框中，粘贴自己的**完整兑换码**，检查首尾没有多余空格或换行。
2. 点击输入框右侧的 **兑换额度**，等待处理结果；处理中不要重复提交。

**不需要选择上方的充值金额，也不需要点击 Card 等付款方式。** 兑换到账的额度由兑换码本身决定，与页面上的「自定义金额」无关。

## 第 3 步：核对到账结果

兑换成功后，页面会显示 **兑换成功！已添加：…**，同时清空兑换码输入框并刷新账户信息。

1. 查看成功提示中的本次到账额度。
2. 回到钱包顶部，核对 **当前余额**；如果页面未及时更新，可刷新钱包后再查看。
3. 余额到账后，按[创建 API Key](/start/api-key/)和[快速接入](/start/quickstart/)开始调用模型。已有 API Key 无需因充值而重新创建。

**账户余额和 API Key 的额度上限是两回事。** 兑换会增加账户余额，不会自动提高某把 API Key 的消费上限。若仍提示额度不足，还需检查该密钥是否有剩余额度，详见[计费与用量核对](/guides/billing/)。

## 常见问题

| 现象 | 检查方式 |
|---|---|
| 找不到兑换入口 | 确认进入的是「钱包」，并滚动到「添加资金」底部；若页面提示兑换未启用或需确认合规条款，联系管理员处理 |
| 点击后提示兑换失败 | 检查兑换码是否复制完整、有无多余空格；兑换码可能已使用、已过期或已停用，请联系发放方核对。失败提示不一定会区分这些原因 |
| 不确定刚才是否兑换成功 | 先查看成功提示和钱包余额，必要时刷新页面；不要靠反复提交同一个码判断是否到账 |
| 兑换成功但 API 仍提示额度不足 | 同时检查账户余额与 API Key 剩余额度；充值不会自动调整密钥的额度上限 |
