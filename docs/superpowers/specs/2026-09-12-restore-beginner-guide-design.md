# 恢复轻松模式旧版新手指南

## 目标

恢复 `7be424a62` 之前的卡片式新手指南，让轻松模式用户继续获得按工具选择、逐步配置和常见错误排查体验，同时保留现有开发者文档中心。

## 已确认的产品边界

- 轻松模式的“新手指南”打开恢复后的旧版卡片式指南。
- 开发者模式的“文档”继续打开现有 `/guide` 文档中心。
- 旧版新手指南仅对已登录用户开放，不恢复原来的公开文档路由。
- 本次忠实恢复旧版指南的内容与交互，不顺带重写或校正 31 个工具教程。

## 路由与外壳

- 新增认证路由 `/beginner-guide`，由 `_authenticated` 路由树保护。
- `/beginner-guide` 不加入 `isOperatorRoute` 的开发者专属前缀，因此：
  - 保存偏好为轻松模式时，页面使用 `TerminalLayout`；
  - 保存偏好为开发者模式时，页面沿用开发者控制台外壳；
  - 访问指南不会改写用户保存的模式偏好。
- 保留 `/guide` 与 `/guide/:slug` 的现有路由、认证、开发者外壳和深链行为。
- `/beginner-guide` 支持旧版搜索参数：
  - `q?: string`：筛选工具卡片；
  - `tool?: string`：直接打开指定工具的配置弹窗；
  - 未知 `tool` 不打开弹窗，页面仍正常显示。

## 模块边界

- 将历史旧版实现恢复到独立模块 `web/src/features/beginner-guide/`，避免与现有 `web/src/features/guide/` 的文章目录、类型和搜索逻辑混用。
- 新模块包含：
  - `index.tsx`：组合旧版页面区块；
  - `data.ts`：31 个工具、使用场景和故障排查数据；
  - `components/address-kit.tsx`：Base URL、掩码密钥和模型 ID 提示；
  - `components/tool-explorer.tsx`：分类筛选、搜索和工具步骤弹窗；
  - `components/help-sections.tsx`：使用场景与错误排查；
  - `route-search.ts`：`q` 与 `tool` 查询参数校验。
- 页面复用现有 `useGuideAddress` 获取当前部署地址，但不依赖新文档中心的文章目录、模型/分组选择器或文档布局。
- 认证布局由父路由提供；恢复后的页面不得再次嵌套 `AuthenticatedLayout`。

## 导航集成

- 轻松模式的以下入口统一指向 `/beginner-guide`：
  - `CONSOLE_NAV` 中的“新手指南”；
  - `EasyTaskDock` 的桌面与移动菜单项；
  - `useSidebarData` 的轻松模式导航项；
  - 两套轻松模式概览中的“需要特定应用的帮助？”和“阅读文档”链接。
- 开发者模式的“文档”入口继续指向 `/guide`。
- 入口复用现有 `Beginner guide` 翻译键和 `BookOpen` 图标，不增加同义文案。

## 内容与安全

- 以提交 `7be424a62^` 中的旧版 `data.ts` 和三个组件为恢复基准。
- 所有地址占位符继续由运行时站点地址填充，禁止硬编码部署域名。
- API Key 始终使用掩码示例，页面不得调用密钥列表或密钥揭示接口。
- 旧版 31 个工具教程按历史版本恢复；教程事实更新、推荐策略调整和内容删改另行处理。
- 动态工具文案必须在 `en`、`zh`、`zh-TW`、`fr`、`ja`、`ru`、`vi` 七个 locale 中存在，并保持地址占位符一致。

## 状态与降级

- 搜索无结果时显示旧版空状态，不抛出路由错误。
- 未知 `tool` 参数不打开弹窗，工具列表仍可浏览。
- 运行时地址状态沿用 `useGuideAddress` 的现有安全降级。
- 未登录访问由认证路由统一转入现有登录流程；不创建独立登录逻辑。

## 测试设计

- 导航测试：轻松模式桌面、移动和共享导航均链接 `/beginner-guide`；开发者模式仍链接 `/guide`。
- 路由测试：匿名访问受认证保护，轻松模式访问不触发开发者路由覆盖。
- 组件测试：工具分类、文本搜索、指定工具弹窗、复制内容与无结果状态。
- 数据测试：关键工具仍存在，地址占位符可正确替换，API Key 示例保持掩码。
- 国际化测试：旧版动态文案在七个 locale 中均存在且占位符一致。
- 回归测试：现有文档中心的目录、文章深链和开发者入口保持通过。

## 兼容与回滚

- 这是纯前端新增认证路由与导航重定向，不涉及后端、数据库或迁移。
- 恢复代码使用独立目录，回滚时可删除 `/beginner-guide` 路由和模块，并将轻松模式入口重新指向 `/guide`。
- 不修改用户保存的控制台模式，也不迁移本地存储。

## 未采用方案

- 不让 `/guide` 按模式渲染两种内容：同一路径内容不稳定，会破坏深链和可预测性。
- 不删除现有文档中心：会丢失已经完成的文章导航、账户模型筛选和开发者说明。
- 不在新文档中心内增加“双模式”切换：会把一次恢复任务扩大为文档架构改造。
