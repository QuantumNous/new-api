HelloCoder 文档集中说明产品使用方式、客户端接入流程与 API 约定。所有文章均由本地 Markdown 文件生成，并在部署时预渲染为静态页面。

## 从这里开始

如果你第一次接触 HelloCoder，可以按照以下顺序阅读：

1. 阅读快速开始部分，了解文档和账号相关的基础概念。
2. 在客户端接入部分选择你正在使用的工具。
3. 需要自行开发集成时，再查阅 API 参考。

> 文档中的配置值会明确标注用途。涉及密钥的内容不要提交到公开仓库，也不要粘贴到无法确认安全性的页面中。

## 文档如何更新

文档内容位于项目的 `content/docs` 目录。修改 Markdown 后，本地开发环境会显示最新内容；发布环境需要重新构建，新的静态页面才会生效。

### 页面导航

桌面端可以从左侧目录切换文章，并通过右侧的本页目录定位标题。移动端的完整目录位于页面顶部的菜单按钮中。

### 搜索文档

搜索框会匹配文章标题和描述。搜索结果只包含已通过 frontmatter 校验并参与构建的文章。
