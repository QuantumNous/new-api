FLATKEY CLI

One terminal for every media model.

flatkey CLI gives media teams one command line for prompt iteration, asset generation, batch jobs and handoff. Use GPT, Claude, Seedance, image, video and audio models behind one key and one balance.

Install CLIRead docs
# install
npm install -g flatkey

# authenticate once
flatkey login

# generate a campaign asset

Prompt once, switch models fast

Move between image, video, audio and text models without rebuilding prompts in a different web app every time.

Batch the boring work

Generate variants, storyboards, captions and exports from scripts, folders or spreadsheets instead of clicking through every asset.

Keep teams on one bill

Every run uses your flatkey account, budget controls and official-model routing, so creative experiments stay visible.
